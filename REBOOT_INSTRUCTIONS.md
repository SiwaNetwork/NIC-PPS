## 🔧 Что делает патч?

1. **Принудительное использование восходящего фронта**: Все PPS события настраиваются только на восходящий (передний) фронт
2. **Фильтрация на уровне драйвера**: Проверка и принудительная установка флага `PTP_RISING_EDGE`
3. **Сохранение конфигурации**: Драйвер запоминает настройки фронтов для каждого пина

## ⚠️ Устранение неполадок

### Проблема: Ядро 6.8.0 не загрузилось

**Решение:**
1. Перезагрузитесь снова
2. В меню GRUB вручную выберите ядро 6.8.0-84-generic
3. После загрузки выполните: `sudo grub-set-default "Advanced options for Ubuntu>Ubuntu, with Linux 6.8.0-84-generic"`

### Проблема: Скрипт apply_patch_after_reboot.sh выдает ошибку

**Решение:**
```bash
# Проверьте версию ядра
uname -r

# Проверьте наличие исходников
ls -la /usr/src/linux-source-6.8.0.tar.bz2

# Если исходников нет, установите:
sudo apt-get install linux-source-6.8.0
```

### Проблема: Компиляция драйвера не удается

**Решение:**
```bash
# Установите необходимые пакеты
sudo apt-get install build-essential linux-headers-$(uname -r)

# Попробуйте снова
sudo ./scripts/apply_patch_after_reboot.sh
```

### Проблема: Интерфейс не поднимается после перезагрузки драйвера

**Решение:**
```bash
# Проверьте статус интерфейса
ip link show enp3s0

# Поднимите вручную
sudo ip link set enp3s0 up

# Проверьте логи ядра
dmesg | grep igc | tail -20
```

## 🔙 Откат изменений

Если что-то пошло не так, вы можете вернуться к ядру 6.14.0:

```bash
sudo grub-set-default 0
sudo reboot
```

Или восстановить оригинальный драйвер:

```bash
# Найдите резервную копию
ls -la /lib/modules/6.8.0-84-generic/kernel/drivers/net/ethernet/intel/igc/igc.ko.backup*

# Восстановите её
sudo cp /lib/modules/6.8.0-84-generic/kernel/drivers/net/ethernet/intel/igc/igc.ko.backup.YYYYMMDD_HHMMSS \
        /lib/modules/6.8.0-84-generic/kernel/drivers/net/ethernet/intel/igc/igc.ko

# Перезагрузите драйвер
sudo modprobe -r igc
sudo modprobe igc
```
